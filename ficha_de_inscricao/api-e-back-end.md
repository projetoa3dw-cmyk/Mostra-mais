# API e Back-End

centraliza toda a lógica de negócios, autenticação e persistência de dados que alimenta a Vitrine Virtual EXPOUNA. Construída sob a especificação OpenAPI 3.1.0, ela gerencia consultas públicas de projetos e categorias, além de proteger operações restritas de submissão, edição e moderação docente por meio de autenticação segura baseada em cookies JWT `HttpOnly`. Acesse a referência interativa completa para explorar os endpoints, esquemas de dados e testar requisições em tempo real.
